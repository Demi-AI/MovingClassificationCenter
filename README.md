規格說明書
一、作品名稱

搬家分類所｜新北垃圾分類指南

二、作品目的

協助新北市居民在搬家、整理物品時，快速查找常見物品的分類方向、處理步驟與交付提醒，減少因不確定分類方式而混丟的情況。

三、目標使用者與使用情境
目標使用者：新北市居民，尤其是正在搬家或整理大型、特殊物品的人。
使用情境：使用者輸入物品名稱，或從分類資料庫選擇物品，查看分類與處理方式；遇到大型家具時，可前往新北市官方預約頁面申請清運。

四、主要功能
1. 頂端導覽列：固定顯示於畫面頂端，可跳至物品搜尋、分類小指南、分類資料庫、我的整理清單及大型家具預約區。手機版可橫向滑動選單。
2. 物品搜尋：可輸入物品名稱或點選快速範例，查看網站整理的分類結果。
3. 分類資料庫：可依物品名稱、別名、分類或說明搜尋，也可使用分類選單篩選。
4. 分類結果：顯示分類方向、處理說明、建議步驟、注意事項及相關官方資料來源；可複製處理方式。
5. 查無結果提示：建議使用常見名稱、材質或用途搜尋，並提供新北市官方易查通入口。
6. 收藏：可加入或取消收藏，並在「我的整理清單」查看或移除。
7. 最近查詢：自動保存最近 12 筆成功查詢，可重新查看、移除單筆或清除紀錄。
8. 分類小指南：提供紙類、容器、電池與燈管、玻璃、廚餘及大型物品的處理提醒。
9. 大型家具預約：提供前往新北市官方大型家具預約表的入口，並提醒使用者依核准結果與時間排出。
10. 瀏覽器儲存與響應式版面：收藏與查詢紀錄存放於使用者目前的瀏覽器；頁面可在桌機與手機上操作。

五、資料來源與功能限制

分類指南依據頁面列出的新北市政府環保局公開資料整理，並非完整搬運官方易查通資料庫。網站目前沒有串接官方即時分類 API；若網站查無品項，使用者可前往官方易查通確認。收藏及查詢紀錄也只保存在目前瀏覽器，不會跨裝置同步。
大型家具預約由新北市官方頁面受理；本網站提供預約入口與流程提醒，不會代替使用者送出預約。

六、實作方式

網站整理為單一 index.html，CSS 樣式與 JavaScript 功能直接寫在 HTML 內，無需另外安裝程式或資料庫。

七、完成檢核
導覽列可跳至各指定區塊。
搜尋與分類篩選可操作。
分類結果、查無結果提示、收藏及最近查詢可使用。
收藏及查詢紀錄可在同一瀏覽器重新開啟後保留。
頁面包含官方資料來源與大型家具預約入口。
手機版可使用搜尋、導覽與清單功能。
